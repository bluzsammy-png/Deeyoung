EMERGENCY STOP (§18) — one visible tap, never buried
1. Disables all new automation immediately
2. Cancels eligible pending orders + pending approvals
3. Blocks new SENTINEL actions in any mode
4. Writes immutable audit event + notifies user
5. Requires explicit re-arm to resume
